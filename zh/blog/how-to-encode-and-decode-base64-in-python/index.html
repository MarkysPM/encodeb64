如何在 Python 中进行 Base64 编码和解码

2026年11月阅读时间约 7 分钟

Python 标准库的 base64 模块已经包含了处理 Base64 所需的一切。最重要的一点是：它处理的是字节，而不是文本字符串。初学者的大多数错误都源于忘记了这一点。本文介绍如何编码和解码文本与文件、使用 URL 安全的变体，并处理你最可能遇到的错误。

编码字符串

用 .encode() 把字符串转换为字节，把字节传给 b64encode()，再用 .decode() 把结果转回字符串：

import base64 text = 'Hello, World!' encoded = base64.b64encode(text.encode('utf-8')).decode('ascii') print(encoded) # SGVsbG8sIFdvcmxkIQ==

b64encode() 返回的是 bytes 对象，例如 b'SGVsbG8sIFdvcmxkIQ=='。用 'ascii' 解码即可得到普通字符串，这样做是安全的，因为 Base64 的输出只包含 ASCII 字符。

解码字符串

import base64 encoded = 'SGVsbG8sIFdvcmxkIQ==' decoded = base64.b64decode(encoded).decode('utf-8') print(decoded) # Hello, World!

b64decode() 既接受 str（仅含 ASCII 字符），也接受 bytes。它始终返回 bytes，所以在期望得到文本时请调用 .decode('utf-8')。如果原始数据是二进制的（例如图片），就保持为字节。

为什么会出现“a bytes-like object is required”

如果把普通字符串传给 b64encode()，你会看到：

TypeError: a bytes-like object is required, not 'str'

解决办法是先把字符串编码为字节：base64.b64encode('text'.encode('utf-8'))。这是 Python 中最常见的 Base64 错误。

编码和解码文件

以二进制模式（'rb' 和 'wb'）打开文件，这样 Python 就不会尝试把字节当作文本来解释：

import base64 # Encode a file with open('photo.png', 'rb') as f: encoded = base64.b64encode(f.read()).decode('ascii') # Decode it back to a file with open('copy.png', 'wb') as f: f.write(base64.b64decode(encoded))

处理超大文件时，不要一次性全部读入内存。base64.encode(input, output) 和 base64.decode(input, output) 使用文件对象，并分块处理数据。

构建 data URI

要在 HTML 或 CSS 中内嵌图片，请在 Base64 文本前加上媒体类型：

import base64 with open('logo.png', 'rb') as f: data = base64.b64encode(f.read()).decode('ascii') data_uri = f'data:image/png;base64,{data}'

如果你不想写代码，图片转 Base64 工具可以在浏览器中得到同样的结果。

URL 安全的 Base64

标准 Base64 使用 + 和 /，它们在 URL 中有特殊含义。该模块提供了 URL 安全的版本，改用 - 和 _：

import base64 data = b'subjects?_d' safe = base64.urlsafe_b64encode(data).decode('ascii') print(safe) # c3ViamVjdHM_X2Q= print(base64.urlsafe_b64decode(safe)) # b'subjects?_d'

JWT 使用的就是这种变体，不过 JWT 还会去掉 = 填充（见下文）。更多背景请阅读 Base64URL 与 Base64。

修复“Incorrect padding”错误

缺少末尾 = 字符的 Base64 数据（在 JWT 和 URL 中很常见）会在解码时报错：

binascii.Error: Incorrect padding

解码之前先恢复填充：

import base64 def b64url_decode(value: str) -> bytes: value += '=' * (-len(value) % 4) return base64.urlsafe_b64decode(value) def b64url_encode(raw: bytes) -> str: return base64.urlsafe_b64encode(raw).rstrip(b'=').decode('ascii')

表达式 -len(value) % 4 给出需要补足的 = 字符数（0、1、2 或 3），使长度成为 4 的倍数。

校验输入

默认情况下，b64decode() 会悄悄丢弃不在 Base64 字母表中的字符。对于带换行的输入这很方便，但在需要拒绝格式错误的数据时就很危险。传入 validate=True 即可启用严格模式：

import base64, binascii try: base64.b64decode('SGVs bG8=', validate=True) except binascii.Error: print('Not valid Base64')

启用 validate=True 后，字符串中的空格会引发错误，而不是被忽略。

其他有用的函数

  • base64.standard_b64encode() 和 standard_b64decode() 是标准字母表的显式名称。
  • base64.encodebytes() 像 MIME 邮件一样，每 76 个字符插入一个换行。
  • base64.b32encode() 和 b16encode() 提供 Base32 和十六进制编码。

速查

  • 编码前必须先把字符串转换为字节：.encode('utf-8')。
  • 编码后的输出是字节；调用 .decode('ascii') 得到字符串。
  • 用 'rb' 和 'wb' 打开文件。
  • 处理 URL 和令牌时使用 urlsafe_b64encode。
  • 输入来自不可信来源时使用 validate=True。
