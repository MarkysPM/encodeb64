Como codificar e decodificar Base64 em JavaScript

Novembro de 20268 min de leitura

O JavaScript oferece várias formas de trabalhar com Base64, e a certa depende de onde o seu código roda. Os navegadores têm btoa() e atob(). O Node.js tem Buffer. Os dois ambientes também podem usar TextEncoder e TextDecoder para tratar Unicode corretamente. Este guia cobre cada abordagem e as armadilhas em que a maioria dos desenvolvedores cai.

Codificação básica com btoa() e atob()

btoa() (binary to ASCII) codifica uma string em Base64, e atob() (ASCII to binary) a decodifica. Estão disponíveis em todos os navegadores modernos e no Node.js 16 ou superior.

const encoded = btoa('Hello, World!'); console.log(encoded); // "SGVsbG8sIFdvcmxkIQ==" const decoded = atob(encoded); console.log(decoded); // "Hello, World!"

Isso funciona para texto ASCII simples. O problema começa com qualquer outra coisa.

O problema do Unicode

btoa() trata cada caractere como um byte, então só aceita caracteres com pontos de código de 0 a 255. Passar um emoji ou a maioria dos textos não latinos gera um erro:

btoa('café ☕'); // Uncaught InvalidCharacterError: String contains an invalid character

A solução é converter primeiro a string em bytes UTF-8 e depois codificar esses bytes.

Codificando texto Unicode corretamente

TextEncoder converte uma string em um Uint8Array de bytes UTF-8. Transforme esses bytes em uma string binária e passe-a para btoa():

function encodeBase64(text) { const bytes = new TextEncoder().encode(text); let binary = ''; bytes.forEach((b) => (binary += String.fromCharCode(b))); return btoa(binary); } function decodeBase64(base64) { const binary = atob(base64); const bytes = Uint8Array.from(binary, (c) => c.charCodeAt(0)); return new TextDecoder().decode(bytes); } encodeBase64('café ☕'); // "Y2Fmw6kg4piV" decodeBase64('Y2Fmw6kg4piV'); // "café ☕"

Use essas duas funções sempre que a entrada puder conter algo além de ASCII básico. Elas também servem para qualquer texto digitado por usuários, como nomes, comentários ou mensagens.

Base64 no Node.js com Buffer

No Node.js, a opção mais simples e rápida é o Buffer, que cuida do UTF-8 para você:

const encoded = Buffer.from('café ☕', 'utf8').toString('base64'); console.log(encoded); // "Y2Fmw6kg4piV" const decoded = Buffer.from(encoded, 'base64').toString('utf8'); console.log(decoded); // "café ☕"

btoa() e atob() também existem no Node.js, mas para código de servidor o Buffer é preferível, pois trabalha diretamente com dados binários e não exige a passagem por uma string.

Base64URL em JavaScript

O Base64URL troca + por -, / por _ e normalmente remove o preenchimento =. No Node.js 15.7 ou superior, você pode pedi-lo diretamente:

Buffer.from('subjects?_d').toString('base64url'); // "c3ViamVjdHM_X2Q"

No navegador, converta você mesmo a saída padrão:

function toBase64Url(base64) { return base64.replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, ''); } function fromBase64Url(base64url) { let base64 = base64url.replace(/-/g, '+').replace(/_/g, '/'); while (base64.length % 4) base64 += '='; return base64; }

Lembre-se de restaurar o preenchimento antes de chamar atob(), porque alguns decodificadores rejeitam entradas cujo tamanho não seja múltiplo de quatro.

Codificando um arquivo ou uma imagem

No navegador, FileReader.readAsDataURL() lê um arquivo e devolve um URI de dados completo, que já contém os dados em Base64:

const input = document.querySelector('input[type="file"]'); input.addEventListener('change', () => { const reader = new FileReader(); reader.onload = () => { console.log(reader.result); // "data:image/png;base64,iVBORw0KGgo..." }; reader.readAsDataURL(input.files[0]); });

Para ficar só com a parte Base64, remova tudo até a primeira vírgula: reader.result.split(',')[1]. Para uma conversão rápida sem código, use o conversor de imagem para Base64.

No Node.js, leia o arquivo em um buffer e codifique-o:

import { readFileSync } from 'node:fs'; const base64 = readFileSync('photo.png').toString('base64');

Erros comuns e soluções

InvalidCharacterError: String contains an invalid character
Causa: você passou para btoa() uma string com caracteres acima do ponto de código 255. Solução: codifique-a primeiro em bytes UTF-8, como mostrado acima.

InvalidCharacterError ao chamar atob()
Causa: a entrada contém caracteres que não estão no alfabeto Base64, geralmente - e _ de uma string Base64URL, ou espaços e quebras de linha. Solução: converta o Base64URL de volta para Base64 padrão e remova espaços das pontas.

O texto decodificado mostra caracteres estranhos como Ã©
Causa: os bytes eram UTF-8, mas foram interpretados como Latin-1, que é o que atob() devolve por padrão. Solução: decodifique os bytes com TextDecoder.

Saída corrompida em arquivos grandes
Causa: montar uma única string enorme com String.fromCharCode(...bytes) pode ultrapassar o limite de argumentos do motor. Solução: percorra os bytes, processe-os em blocos ou use FileReader ou Buffer.

Uma observação sobre as APIs mais novas

Os motores JavaScript mais recentes estão adicionando métodos nativos em Uint8Array para converter de e para Base64. O suporte ainda é desigual entre os navegadores, então consulte as tabelas de compatibilidade atuais antes de depender deles em produção. As funções deste guia funcionam hoje em qualquer lugar.
