Base64 en la línea de comandos: Linux, macOS y Windows

Noviembre de 20266 min de lectura

No necesitas un sitio web ni un script para trabajar con Base64. Todos los sistemas operativos principales incluyen herramientas que pueden codificarlo y decodificarlo desde la terminal, lo cual es útil para inspeccionar tokens, crear secretos para archivos de configuración o convertir archivos pequeños. Esta guía cubre Linux, macOS y Windows, y señala las diferencias que causan resultados confusos.

Linux: el comando base64

El comando base64 de GNU forma parte de coreutils y está instalado en prácticamente todas las distribuciones de Linux.

Codificar una cadena:

echo -n 'Hello, World!' | base64 # SGVsbG8sIFdvcmxkIQ==

Decodificarla:

echo 'SGVsbG8sIFdvcmxkIQ==' | base64 --decode # Hello, World!

Codificar y decodificar archivos:

base64 photo.png > photo.b64 base64 --decode photo.b64 > photo-copy.png

La trampa del salto de línea final

Este es el error más común. El echo simple añade un carácter de salto de línea a su salida, y ese salto pasa a formar parte de los datos que se codifican:

echo 'Hello' | base64 # SGVsbG8K (encodes "Hello\n") echo -n 'Hello' | base64 # SGVsbG8= (encodes "Hello")

Si una contraseña, clave de API o token «no funciona» después de codificarlo en la terminal, lo más probable es que el culpable sea un salto de línea sobrante. Usa siempre echo -n, o usa printf '%s' 'Hello', que se comporta igual en todos los intérpretes de comandos.

Ajuste de línea

base64 de GNU divide su salida cada 76 caracteres. Está bien para archivos, pero no para pegarla en JSON, variables de entorno o cabeceras HTTP. Desactiva el ajuste con -w 0:

base64 -w 0 photo.png

macOS

macOS incluye una versión BSD de base64 que acepta opciones algo distintas. La codificación básica con una tubería funciona igual:

echo -n 'Hello, World!' | base64 echo 'SGVsbG8sIFdvcmxkIQ==' | base64 --decode

Usa -i para un archivo de entrada y -o para uno de salida:

base64 -i photo.png -o photo.b64

La opción de GNU -w 0 no existe en macOS, y las versiones antiguas de macOS usaban -D en lugar de -d o --decode. Si un script debe funcionar en ambos sistemas, comprueba la plataforma o usa openssl, que se explica a continuación.

openssl: la opción portable

OpenSSL está disponible en Linux, macOS y Windows (mediante Git for Windows o WSL) y se comporta de forma coherente:

echo -n 'Hello, World!' | openssl base64 echo 'SGVsbG8sIFdvcmxkIQ==' | openssl base64 -d openssl base64 -in photo.png -out photo.b64

Añade -A para mantener la salida en una sola línea en lugar de dividirla.

Windows PowerShell

PowerShell puede llamar directamente a la clase Convert de .NET. Codificar texto:

[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('Hello, World!')) # SGVsbG8sIFdvcmxkIQ==

Decodificar texto:

[Text.Encoding]::UTF8.GetString([Convert]::FromBase64String('SGVsbG8sIFdvcmxkIQ==')) # Hello, World!

Codificar un archivo a una cadena Base64:

[Convert]::ToBase64String([IO.File]::ReadAllBytes('photo.png'))

Decodificar una cadena Base64 y guardarla en un archivo:

[IO.File]::WriteAllBytes('photo-copy.png', [Convert]::FromBase64String($base64))

Fíjate en que eliges la codificación de texto de forma explícita (UTF8). Si usas Unicode, PowerShell emplea UTF-16 y el resultado será distinto del que producen Linux y macOS.

Windows certutil

La herramienta clásica certutil funciona desde el Símbolo del sistema en cualquier Windows:

certutil -encode photo.png photo.b64 certutil -decode photo.b64 photo-copy.png

Ten en cuenta que certutil -encode envuelve la salida con líneas de cabecera y pie -----BEGIN CERTIFICATE-----. Elimina esas líneas si solo necesitas el texto Base64.

Decodificar Base64URL desde la terminal

Los JWT y muchas API modernas usan el alfabeto seguro para URL y omiten el relleno, así que un simple base64 --decode puede fallar. Convierte antes los caracteres y restaura el relleno:

value='eyJhbGciOiJIUzI1NiJ9' len=$(( ${#value} % 4 )) [ $len -eq 2 ] && value="$value==" [ $len -eq 3 ] && value="$value=" echo "$value" | tr '_-' '/+' | base64 --decode # {"alg":"HS256"}

Para entender por qué estos tokens tienen otro aspecto, lee Cómo usan los tokens JWT la codificación Base64URL.

Comparación rápida

  • Linux: base64, con -w 0 para una sola línea.
  • macOS: base64 con -i y -o; no tiene la opción -w.
  • Multiplataforma: openssl base64.
  • Windows: [Convert] de PowerShell o certutil.

Si solo necesitas algo puntual, el codificador en línea y decodeb64.com hacen lo mismo en tu navegador. Para usar Base64 dentro de programas, consulta las guías de JavaScript y Python.
