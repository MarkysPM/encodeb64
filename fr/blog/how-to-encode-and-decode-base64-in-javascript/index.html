Encoder et décoder Base64 en JavaScript

Novembre 20268 min de lecture

JavaScript offre plusieurs façons de travailler avec Base64, et la bonne dépend de l'endroit où s'exécute votre code. Les navigateurs fournissent btoa() et atob(). Node.js fournit Buffer. Les deux environnements peuvent aussi utiliser TextEncoder et TextDecoder pour gérer correctement Unicode. Ce guide présente chaque approche et les pièges dans lesquels tombent la plupart des développeurs.

Encodage de base avec btoa() et atob()

btoa() (binary to ASCII) encode une chaîne en Base64 et atob() (ASCII to binary) la décode. Elles sont disponibles dans tous les navigateurs modernes et dans Node.js 16 et versions ultérieures.

const encoded = btoa('Hello, World!'); console.log(encoded); // "SGVsbG8sIFdvcmxkIQ==" const decoded = atob(encoded); console.log(decoded); // "Hello, World!"

Cela fonctionne pour du texte ASCII simple. Les problèmes commencent avec tout le reste.

Le problème d'Unicode

btoa() traite chaque caractère comme un octet : elle n'accepte donc que les caractères dont le point de code est compris entre 0 et 255. Lui passer un émoji ou la plupart des textes non latins provoque une erreur :

btoa('café ☕'); // Uncaught InvalidCharacterError: String contains an invalid character

La solution consiste à convertir d'abord la chaîne en octets UTF-8, puis à encoder ces octets.

Encoder correctement du texte Unicode

TextEncoder convertit une chaîne en Uint8Array d'octets UTF-8. Transformez ces octets en chaîne binaire et passez-la à btoa() :

function encodeBase64(text) { const bytes = new TextEncoder().encode(text); let binary = ''; bytes.forEach((b) => (binary += String.fromCharCode(b))); return btoa(binary); } function decodeBase64(base64) { const binary = atob(base64); const bytes = Uint8Array.from(binary, (c) => c.charCodeAt(0)); return new TextDecoder().decode(bytes); } encodeBase64('café ☕'); // "Y2Fmw6kg4piV" decodeBase64('Y2Fmw6kg4piV'); // "café ☕"

Utilisez ces deux fonctions dès que l'entrée peut contenir autre chose que de l'ASCII basique. Elles conviennent aussi à tout texte saisi par des utilisateurs, comme des noms, des commentaires ou des messages.

Base64 dans Node.js avec Buffer

Dans Node.js, l'option la plus simple et la plus rapide est Buffer, qui gère l'UTF-8 pour vous :

const encoded = Buffer.from('café ☕', 'utf8').toString('base64'); console.log(encoded); // "Y2Fmw6kg4piV" const decoded = Buffer.from(encoded, 'base64').toString('utf8'); console.log(decoded); // "café ☕"

btoa() et atob() existent aussi dans Node.js, mais Buffer est préférable pour du code serveur car il travaille directement sur des données binaires, sans passer par une chaîne intermédiaire.

Base64URL en JavaScript

Base64URL remplace + par -, / par _ et supprime généralement le remplissage =. Dans Node.js 15.7 et versions ultérieures, vous pouvez le demander directement :

Buffer.from('subjects?_d').toString('base64url'); // "c3ViamVjdHM_X2Q"

Dans le navigateur, convertissez vous-même la sortie standard :

function toBase64Url(base64) { return base64.replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, ''); } function fromBase64Url(base64url) { let base64 = base64url.replace(/-/g, '+').replace(/_/g, '/'); while (base64.length % 4) base64 += '='; return base64; }

N'oubliez pas de rétablir le remplissage avant d'appeler atob(), car certains décodeurs rejettent les entrées dont la longueur n'est pas un multiple de quatre.

Encoder un fichier ou une image

Dans le navigateur, FileReader.readAsDataURL() lit un fichier et renvoie un URI de données complet qui contient déjà les données en Base64 :

const input = document.querySelector('input[type="file"]'); input.addEventListener('change', () => { const reader = new FileReader(); reader.onload = () => { console.log(reader.result); // "data:image/png;base64,iVBORw0KGgo..." }; reader.readAsDataURL(input.files[0]); });

Pour ne garder que la partie Base64, supprimez tout ce qui précède la première virgule : reader.result.split(',')[1]. Pour une conversion rapide sans code, utilisez le convertisseur d'image en Base64.

Dans Node.js, lisez le fichier dans un tampon et encodez-le :

import { readFileSync } from 'node:fs'; const base64 = readFileSync('photo.png').toString('base64');

Erreurs courantes et solutions

InvalidCharacterError: String contains an invalid character
Cause : vous avez passé à btoa() une chaîne contenant des caractères au-delà du point de code 255. Solution : encodez-la d'abord en octets UTF-8, comme indiqué plus haut.

InvalidCharacterError lors de l'appel à atob()
Cause : l'entrée contient des caractères absents de l'alphabet Base64, souvent - et _ d'une chaîne Base64URL, ou des espaces et sauts de ligne. Solution : reconvertissez le Base64URL en Base64 standard et supprimez les espaces aux extrémités.

Cause : les octets étaient en UTF-8 mais ont été interprétés comme du Latin-1, ce que renvoie atob() par défaut. Solution : décodez les octets avec TextDecoder.

Sortie corrompue avec de gros fichiers
Cause : construire une seule énorme chaîne avec String.fromCharCode(...bytes) peut dépasser la limite d'arguments du moteur. Solution : parcourez les octets, traitez-les par blocs ou utilisez FileReader ou Buffer.

Une remarque sur les API récentes

Les moteurs JavaScript récents ajoutent des méthodes intégrées à Uint8Array pour convertir vers et depuis Base64. La prise en charge reste inégale selon les navigateurs ; consultez donc les tableaux de compatibilité actuels avant de vous y fier en production. Les fonctions de ce guide marchent aujourd'hui partout.
