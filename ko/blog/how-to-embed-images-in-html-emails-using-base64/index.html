Base64를 사용해 HTML 이메일에 이미지를 삽입하는 방법

2026년 8월읽는 시간 약 5분

이미지가 포함된 HTML 이메일을 보냈는데 수신자의 받은 편지함에서 이미지가 깨져 보인 적이 있다면, 당신만 그런 것이 아닙니다. 많은 이메일 클라이언트는 기본적으로 외부에 호스팅된 이미지를 차단합니다. 신뢰할 수 있는 해결책 중 하나는 Base64 인코딩을 사용해 이미지를 이메일에 직접 삽입하는 것입니다. 이 기법은 이미지의 바이너리 데이터를 HTML 안에 인라인으로 넣을 수 있는 텍스트 문자열로 변환합니다.

HTML 이메일에서 이미지가 깨지는 이유

이메일의 외부 이미지는 수신자의 이메일 클라이언트가 HTTP 요청을 보내 불러오는 방식에 의존합니다. Microsoft Outlook, Apple Mail, 기업용 이메일 시스템 등 많은 클라이언트는 보안상의 이유로 이러한 요청을 기본적으로 차단합니다. 그 결과 정성껏 디자인한 배너나 로고가 있어야 할 자리에 깨진 이미지 아이콘이 나타납니다.

Base64 이미지 삽입이란?

Base64 인코딩은 바이너리 데이터(이미지 파일 등)를 ASCII 문자열로 변환합니다. Base64로 인코딩된 이미지를 HTML 이메일에 삽입하면 이미지 데이터가 이메일 자체와 함께 전달되므로 외부 HTTP 요청이 필요 없습니다. HTML은 다음과 같은 모습입니다.

<img src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..." alt="회사 로고" />

data: 접두사 뒤에 MIME 타입과 Base64 문자열이 이어지는 것을 Data URI라고 합니다. HTML을 렌더링하는 모든 주요 이메일 클라이언트는 Data URI로부터 이미지를 올바르게 표시합니다.

단계별 가이드: 이미지를 Base64로 인코딩하기

1단계 — 이미지를 선택하세요. 크기를 작게 유지하세요. Base64 인코딩은 파일 크기를 약 33% 증가시키며, 큰 이미지를 삽입하면 이메일 파일 크기가 크게 늘어나 스팸 필터에 걸릴 수 있습니다. 인코딩 전 이미지 크기를 50KB 이하로 맞추는 것을 목표로 하세요.

2단계 — 이미지를 인코딩하세요. encodeb64.com/image-to-base64로 이동해 이미지를 업로드 영역에 드래그 앤 드롭하고, 출력 형식으로 "Data URI (HTML/CSS)"를 선택한 뒤 Convert를 클릭하세요. 이 도구는 모든 처리를 브라우저 안에서 수행하므로 이미지가 기기 밖으로 나가지 않습니다.

3단계 — Data URI를 복사하세요. 결과는 다음과 같은 형태입니다: data:image/png;base64,iVBORw0KGgo... 전체 문자열을 복사하세요.

4단계 — HTML 이메일 템플릿에 붙여넣으세요. 이미지의 외부 src를 Data URI로 교체하세요:

<img src="data:image/png;base64,iVBORw0KGgo..." alt="설명" width="200" height="60" />

항상 width와 height 속성을 명시적으로 포함하세요. 일부 이메일 클라이언트는 이미지를 올바른 크기로 렌더링하기 위해 이 속성들이 필요합니다.

지원되는 이미지 형식

대부분의 이메일 클라이언트는 PNG와 JPEG Data URI를 지원합니다. 로고와 아이콘에는 투명도를 지원하는 PNG를 추천합니다. Data URI에서 애니메이션 GIF는 피하세요. 대부분의 클라이언트에서는 첫 프레임만 표시됩니다. SVG Data URI는 이메일 클라이언트에서 지원이 좋지 않아 피해야 합니다.

파일 크기 관련 고려사항

Base64 삽입은 로고, 아이콘, 서명, 장식용 구분선 같은 작은 이미지에 이상적입니다. 큰 히어로 이미지나 포토 배너의 경우, 외부에 호스팅하고 대체 alt 텍스트를 사용하는 것이 좋습니다. 큰 이미지를 삽입하면 이메일이 크기 제한을 초과할 수 있고(많은 서버가 10MB가 넘는 이메일을 거부합니다) 로딩 시간도 크게 늘어납니다.

이메일에서 Base64를 사용하지 말아야 할 때

  • 100KB가 넘는 뉴스레터 히어로 이미지 — 대신 CDN에 호스팅된 이미지를 사용하세요
  • 애니메이션 GIF — 대부분의 클라이언트에서 Base64는 애니메이션을 잃습니다
  • 이미지가 많은 이메일 — 모두 삽입하면 파일 크기가 급격히 커집니다
