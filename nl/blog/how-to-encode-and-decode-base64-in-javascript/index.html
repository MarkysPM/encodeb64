Base64 coderen en decoderen in JavaScript

November 20268 min. leestijd

JavaScript biedt meerdere manieren om met Base64 te werken, en de juiste hangt af van waar je code draait. Browsers bieden btoa() en atob(). Node.js biedt Buffer. In beide omgevingen kun je ook TextEncoder en TextDecoder gebruiken om Unicode correct af te handelen. Deze gids behandelt elke aanpak en de valkuilen waar de meeste ontwikkelaars in trappen.

Basiscodering met btoa() en atob()

btoa() (binary to ASCII) codeert een tekenreeks naar Base64 en atob() (ASCII to binary) decodeert die weer. Ze zijn beschikbaar in alle moderne browsers en in Node.js 16 en nieuwer.

const encoded = btoa('Hello, World!'); console.log(encoded); // "SGVsbG8sIFdvcmxkIQ==" const decoded = atob(encoded); console.log(decoded); // "Hello, World!"

Dit werkt voor gewone ASCII-tekst. Het probleem begint bij al het andere.

Het Unicode-probleem

btoa() behandelt elk teken als één byte en accepteert dus alleen tekens met codepunten van 0 tot 255. Een emoji of de meeste niet-Latijnse tekst veroorzaakt een fout:

btoa('café ☕'); // Uncaught InvalidCharacterError: String contains an invalid character

De oplossing is om de tekenreeks eerst naar UTF-8-bytes om te zetten en daarna die bytes te coderen.

Unicode-tekst correct coderen

TextEncoder zet een tekenreeks om in een Uint8Array met UTF-8-bytes. Maak van die bytes een binaire tekenreeks en geef die aan btoa():

function encodeBase64(text) { const bytes = new TextEncoder().encode(text); let binary = ''; bytes.forEach((b) => (binary += String.fromCharCode(b))); return btoa(binary); } function decodeBase64(base64) { const binary = atob(base64); const bytes = Uint8Array.from(binary, (c) => c.charCodeAt(0)); return new TextDecoder().decode(bytes); } encodeBase64('café ☕'); // "Y2Fmw6kg4piV" decodeBase64('Y2Fmw6kg4piV'); // "café ☕"

Gebruik deze twee functies altijd wanneer de invoer meer dan gewoon ASCII kan bevatten. Ze werken ook voor alle tekst die gebruikers invoeren, zoals namen, opmerkingen of berichten.

Base64 in Node.js met Buffer

In Node.js is Buffer de eenvoudigste en snelste optie; het regelt UTF-8 voor je:

const encoded = Buffer.from('café ☕', 'utf8').toString('base64'); console.log(encoded); // "Y2Fmw6kg4piV" const decoded = Buffer.from(encoded, 'base64').toString('utf8'); console.log(decoded); // "café ☕"

btoa() en atob() bestaan ook in Node.js, maar voor servercode heeft Buffer de voorkeur omdat het direct met binaire gegevens werkt en geen omweg via een tekenreeks nodig heeft.

Base64URL in JavaScript

Base64URL vervangt + door -, / door _ en laat meestal de =-padding weg. In Node.js 15.7 en nieuwer kun je het rechtstreeks opvragen:

Buffer.from('subjects?_d').toString('base64url'); // "c3ViamVjdHM_X2Q"

In de browser zet je de standaarduitvoer zelf om:

function toBase64Url(base64) { return base64.replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, ''); } function fromBase64Url(base64url) { let base64 = base64url.replace(/-/g, '+').replace(/_/g, '/'); while (base64.length % 4) base64 += '='; return base64; }

Vergeet niet de padding te herstellen voordat je atob() aanroept, omdat sommige decoders invoer afwijzen waarvan de lengte geen veelvoud van vier is.

Een bestand of afbeelding coderen

In de browser leest FileReader.readAsDataURL() een bestand en geeft een volledige data-URI terug die de Base64-gegevens al bevat:

const input = document.querySelector('input[type="file"]'); input.addEventListener('change', () => { const reader = new FileReader(); reader.onload = () => { console.log(reader.result); // "data:image/png;base64,iVBORw0KGgo..." }; reader.readAsDataURL(input.files[0]); });

Wil je alleen het Base64-deel houden, verwijder dan alles tot de eerste komma: reader.result.split(',')[1]. Voor een snelle conversie zonder code gebruik je de afbeelding-naar-Base64-converter.

Lees in Node.js het bestand in een buffer en codeer die:

import { readFileSync } from 'node:fs'; const base64 = readFileSync('photo.png').toString('base64');

Veelvoorkomende fouten en oplossingen

InvalidCharacterError: String contains an invalid character
Oorzaak: je gaf btoa() een tekenreeks met tekens boven codepunt 255. Oplossing: codeer die eerst naar UTF-8-bytes, zoals hierboven getoond.

InvalidCharacterError bij het aanroepen van atob()
Oorzaak: de invoer bevat tekens die niet in het Base64-alfabet staan, vaak - en _ uit een Base64URL-tekenreeks, of spaties en regeleinden. Oplossing: zet Base64URL terug naar standaard-Base64 en verwijder witruimte aan de randen.

Oorzaak: de bytes waren UTF-8 maar werden als Latin-1 gelezen, wat atob() standaard teruggeeft. Oplossing: decodeer de bytes met TextDecoder.

Beschadigde uitvoer bij grote bestanden
Oorzaak: één enorme tekenreeks opbouwen met String.fromCharCode(...bytes) kan de argumentlimiet van de engine overschrijden. Oplossing: loop over de bytes, verwerk ze in delen of gebruik FileReader of Buffer.

Een opmerking over nieuwere API's

Nieuwere JavaScript-engines voegen ingebouwde methoden toe aan Uint8Array om van en naar Base64 om te zetten. De ondersteuning verschilt nog per browser, dus raadpleeg de actuele compatibiliteitstabellen voordat je er in productie op vertrouwt. De functies in deze gids werken vandaag overal.
