How to Encode and Decode Base64 in Python

November 20267 min read

Python includes everything you need for Base64 in the standard library’s base64 module. The most important thing to remember is that it works on bytes, not on text strings. Most beginner errors come from forgetting that. This guide shows how to encode and decode text and files, use the URL-safe variant, and deal with the errors you are likely to meet.

Encoding a String

Convert the string to bytes with .encode(), pass the bytes to b64encode(), then convert the result back to a string with .decode():

import base64 text = 'Hello, World!' encoded = base64.b64encode(text.encode('utf-8')).decode('ascii') print(encoded) # SGVsbG8sIFdvcmxkIQ==

b64encode() returns a bytes object such as b'SGVsbG8sIFdvcmxkIQ=='. Decoding it with 'ascii' gives you a normal string, which is safe because Base64 output only contains ASCII characters.

Decoding a String

import base64 encoded = 'SGVsbG8sIFdvcmxkIQ==' decoded = base64.b64decode(encoded).decode('utf-8') print(decoded) # Hello, World!

b64decode() accepts either a str (containing only ASCII characters) or bytes. It always returns bytes, so call .decode('utf-8') when you expect text. If the original data was binary, such as an image, keep it as bytes.

Why You Get “a bytes-like object is required”

If you pass a normal string to b64encode() you will see:

TypeError: a bytes-like object is required, not 'str'

The fix is to encode the string to bytes first: base64.b64encode('text'.encode('utf-8')). This is the single most common Base64 error in Python.

Encoding and Decoding Files

Open files in binary mode ('rb' and 'wb') so Python does not try to interpret the bytes as text:

import base64 # Encode a file with open('photo.png', 'rb') as f: encoded = base64.b64encode(f.read()).decode('ascii') # Decode it back to a file with open('copy.png', 'wb') as f: f.write(base64.b64decode(encoded))

For very large files, avoid reading everything into memory. base64.encode(input, output) and base64.decode(input, output) work with file objects and process the data in chunks.

Building a Data URI

To embed an image in HTML or CSS, prefix the Base64 text with the media type:

import base64 with open('logo.png', 'rb') as f: data = base64.b64encode(f.read()).decode('ascii') data_uri = f'data:image/png;base64,{data}'

For a no-code option, the Image to Base64 converter produces the same result in your browser.

URL-Safe Base64

Standard Base64 uses + and /, which have special meaning in URLs. The module provides URL-safe versions that use - and _ instead:

import base64 data = b'subjects?_d' safe = base64.urlsafe_b64encode(data).decode('ascii') print(safe) # c3ViamVjdHM_X2Q= print(base64.urlsafe_b64decode(safe)) # b'subjects?_d'

This is the variant used by JWT, although JWTs also strip the = padding (see below). For background, read Base64URL vs Base64.

Fixing “Incorrect padding” Errors

Base64 data without its trailing = characters, which is common in JWTs and URLs, raises an error when decoded:

binascii.Error: Incorrect padding

Restore the padding before decoding:

import base64 def b64url_decode(value: str) -> bytes: value += '=' * (-len(value) % 4) return base64.urlsafe_b64decode(value) def b64url_encode(raw: bytes) -> str: return base64.urlsafe_b64encode(raw).rstrip(b'=').decode('ascii')

The expression -len(value) % 4 gives the number of = characters needed (0, 1, 2 or 3) to reach a multiple of four.

Validating Input

By default b64decode() silently discards characters that are not in the Base64 alphabet. That is convenient for input with line breaks, but dangerous when you need to reject malformed data. Pass validate=True to make it strict:

import base64, binascii try: base64.b64decode('SGVs bG8=', validate=True) except binascii.Error: print('Not valid Base64')

With validate=True the space inside the string causes an error instead of being ignored.

Other Useful Functions

  • base64.standard_b64encode() and standard_b64decode() are explicit names for the standard alphabet.
  • base64.encodebytes() inserts a newline every 76 characters, like MIME email.
  • base64.b32encode() and b16encode() provide Base32 and hexadecimal encodings.

Quick Reference

  • Strings must become bytes before encoding: .encode('utf-8').
  • Encoded output is bytes; call .decode('ascii') for a string.
  • Open files with 'rb' and 'wb'.
  • Use urlsafe_b64encode for URLs and tokens.
  • Use validate=True when the input comes from an untrusted source.
