Python에서 Base64 인코딩과 디코딩하는 방법

2026년 11월읽는 시간 약 7분

Python은 표준 라이브러리의 base64 모듈에 Base64에 필요한 모든 것을 갖추고 있습니다. 가장 중요한 점은 텍스트 문자열이 아니라 바이트를 다룬다는 사실을 기억하는 것입니다. 초보자의 오류 대부분은 이를 잊어서 생깁니다. 이 가이드에서는 텍스트와 파일을 인코딩·디코딩하는 방법, URL 안전 변형을 사용하는 방법, 마주칠 가능성이 높은 오류를 해결하는 방법을 보여 줍니다.

문자열 인코딩하기

.encode()로 문자열을 바이트로 변환하고, 그 바이트를 b64encode()에 넘긴 다음, 결과를 .decode()로 다시 문자열로 바꿉니다.

import base64 text = 'Hello, World!' encoded = base64.b64encode(text.encode('utf-8')).decode('ascii') print(encoded) # SGVsbG8sIFdvcmxkIQ==

b64encode()는 b'SGVsbG8sIFdvcmxkIQ==' 같은 bytes 객체를 반환합니다. 'ascii'로 디코딩하면 일반 문자열이 되며, Base64 출력에는 ASCII 문자만 들어 있으므로 안전합니다.

문자열 디코딩하기

import base64 encoded = 'SGVsbG8sIFdvcmxkIQ==' decoded = base64.b64decode(encoded).decode('utf-8') print(decoded) # Hello, World!

b64decode()는 str(ASCII 문자만 포함)과 bytes 모두 받을 수 있습니다. 항상 bytes를 반환하므로, 텍스트를 기대한다면 .decode('utf-8')을 호출하세요. 원본 데이터가 이미지 같은 바이너리였다면 바이트 그대로 두세요.

“a bytes-like object is required”가 나오는 이유

일반 문자열을 b64encode()에 넘기면 다음 오류가 나타납니다.

TypeError: a bytes-like object is required, not 'str'

해결책은 문자열을 먼저 바이트로 변환하는 것입니다: base64.b64encode('text'.encode('utf-8')). Python에서 가장 흔한 Base64 오류입니다.

파일 인코딩과 디코딩

Python이 바이트를 텍스트로 해석하려 하지 않도록 파일은 바이너리 모드('rb', 'wb')로 여세요.

import base64 # Encode a file with open('photo.png', 'rb') as f: encoded = base64.b64encode(f.read()).decode('ascii') # Decode it back to a file with open('copy.png', 'wb') as f: f.write(base64.b64decode(encoded))

아주 큰 파일은 전부 메모리로 읽지 마세요. base64.encode(input, output)와 base64.decode(input, output)는 파일 객체를 다루며 데이터를 청크 단위로 처리합니다.

data URI 만들기

HTML이나 CSS에 이미지를 포함하려면 Base64 텍스트 앞에 미디어 유형을 붙입니다.

import base64 with open('logo.png', 'rb') as f: data = base64.b64encode(f.read()).decode('ascii') data_uri = f'data:image/png;base64,{data}'

코드 없이 하고 싶다면 이미지 Base64 변환기가 브라우저에서 같은 결과를 만들어 줍니다.

URL 안전 Base64

표준 Base64는 URL에서 특별한 의미를 갖는 +와 /를 사용합니다. 이 모듈은 대신 -와 _를 사용하는 URL 안전 버전을 제공합니다.

import base64 data = b'subjects?_d' safe = base64.urlsafe_b64encode(data).decode('ascii') print(safe) # c3ViamVjdHM_X2Q= print(base64.urlsafe_b64decode(safe)) # b'subjects?_d'

JWT가 사용하는 변형이 바로 이것입니다. 다만 JWT는 = 패딩도 제거합니다(아래 참고). 배경 지식은 Base64URL vs Base64에서 확인하세요.

“Incorrect padding” 오류 해결하기

JWT와 URL에서 흔하듯 끝의 = 문자가 없는 Base64 데이터는 디코딩할 때 오류를 일으킵니다.

binascii.Error: Incorrect padding

디코딩하기 전에 패딩을 복원하세요.

import base64 def b64url_decode(value: str) -> bytes: value += '=' * (-len(value) % 4) return base64.urlsafe_b64decode(value) def b64url_encode(raw: bytes) -> str: return base64.urlsafe_b64encode(raw).rstrip(b'=').decode('ascii')

식 -len(value) % 4는 길이를 4의 배수로 맞추는 데 필요한 = 문자의 개수(0, 1, 2, 3)를 알려 줍니다.

입력 검증하기

기본적으로 b64decode()는 Base64 알파벳에 없는 문자를 조용히 버립니다. 줄 바꿈이 포함된 입력에는 편리하지만, 잘못된 데이터를 거부해야 할 때는 위험합니다. validate=True를 넘기면 엄격 모드가 됩니다.

import base64, binascii try: base64.b64decode('SGVs bG8=', validate=True) except binascii.Error: print('Not valid Base64')

validate=True를 지정하면 문자열 안의 공백이 무시되지 않고 오류를 일으킵니다.

그 밖의 유용한 함수

  • base64.standard_b64encode()와 standard_b64decode()는 표준 알파벳을 명시하는 이름입니다.
  • base64.encodebytes()는 MIME 이메일처럼 76자마다 줄 바꿈을 삽입합니다.
  • base64.b32encode()와 b16encode()는 Base32와 16진수 인코딩을 제공합니다.

빠른 참고

  • 인코딩 전에 문자열을 바이트로 변환해야 합니다: .encode('utf-8').
  • 인코딩된 출력은 바이트입니다. 문자열이 필요하면 .decode('ascii')를 호출하세요.
  • 파일은 'rb'와 'wb'로 여세요.
  • URL과 토큰에는 urlsafe_b64encode를 사용하세요.
  • 입력이 신뢰할 수 없는 출처에서 온다면 validate=True를 사용하세요.
