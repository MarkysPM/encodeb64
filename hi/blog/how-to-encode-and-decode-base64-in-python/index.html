Python में Base64 एन्कोड और डिकोड कैसे करें

नवंबर 20267 मिनट पढ़ने का समय

Python की स्टैंडर्ड लाइब्रेरी के base64 मॉड्यूल में Base64 के लिए ज़रूरी सब कुछ मौजूद है। सबसे ज़रूरी बात याद रखने की यह है कि यह टेक्स्ट स्ट्रिंग पर नहीं, बाइट्स पर काम करता है। शुरुआती लोगों की ज़्यादातर त्रुटियाँ इसे भूलने से आती हैं। यह गाइड दिखाती है कि टेक्स्ट और फ़ाइलों को कैसे एन्कोड और डिकोड करें, URL-सुरक्षित रूप कैसे इस्तेमाल करें, और संभावित त्रुटियों से कैसे निपटें।

स्ट्रिंग को एन्कोड करना

.encode() से स्ट्रिंग को बाइट्स में बदलें, बाइट्स को b64encode() को दें, फिर नतीजे को .decode() से वापस स्ट्रिंग बनाएँ:

import base64 text = 'Hello, World!' encoded = base64.b64encode(text.encode('utf-8')).decode('ascii') print(encoded) # SGVsbG8sIFdvcmxkIQ==

b64encode() एक bytes ऑब्जेक्ट लौटाता है, जैसे b'SGVsbG8sIFdvcmxkIQ=='। इसे 'ascii' से डिकोड करने पर सामान्य स्ट्रिंग मिलती है, जो सुरक्षित है क्योंकि Base64 आउटपुट में केवल ASCII वर्ण होते हैं।

स्ट्रिंग को डिकोड करना

import base64 encoded = 'SGVsbG8sIFdvcmxkIQ==' decoded = base64.b64decode(encoded).decode('utf-8') print(decoded) # Hello, World!

b64decode() str (केवल ASCII वर्णों वाली) और bytes दोनों स्वीकार करता है। यह हमेशा bytes लौटाता है, इसलिए जब आप टेक्स्ट की अपेक्षा करें तो .decode('utf-8') कॉल करें। अगर मूल डेटा बाइनरी था, जैसे इमेज, तो उसे बाइट्स के रूप में ही रखें।

“a bytes-like object is required” क्यों आता है

अगर आप b64encode() को सामान्य स्ट्रिंग देते हैं, तो आपको यह दिखेगा:

TypeError: a bytes-like object is required, not 'str'

समाधान यह है कि पहले स्ट्रिंग को बाइट्स में बदलें: base64.b64encode('text'.encode('utf-8'))। यह Python में सबसे आम Base64 त्रुटि है।

फ़ाइलें एन्कोड और डिकोड करना

फ़ाइलों को बाइनरी मोड ('rb' और 'wb') में खोलें ताकि Python बाइट्स को टेक्स्ट की तरह समझने की कोशिश न करे:

import base64 # Encode a file with open('photo.png', 'rb') as f: encoded = base64.b64encode(f.read()).decode('ascii') # Decode it back to a file with open('copy.png', 'wb') as f: f.write(base64.b64decode(encoded))

बहुत बड़ी फ़ाइलों के लिए सब कुछ मेमोरी में न पढ़ें। base64.encode(input, output) और base64.decode(input, output) फ़ाइल ऑब्जेक्ट के साथ काम करते हैं और डेटा को हिस्सों में प्रोसेस करते हैं।

data URI बनाना

HTML या CSS में इमेज एम्बेड करने के लिए Base64 टेक्स्ट से पहले मीडिया टाइप लगाएँ:

import base64 with open('logo.png', 'rb') as f: data = base64.b64encode(f.read()).decode('ascii') data_uri = f'data:image/png;base64,{data}'

अगर आप बिना कोड के करना चाहें, तो इमेज से Base64 कन्वर्टर आपके ब्राउज़र में वही नतीजा देता है।

URL-सुरक्षित Base64

मानक Base64 + और / का उपयोग करता है, जिनका URL में विशेष अर्थ होता है। मॉड्यूल URL-सुरक्षित संस्करण देता है जो इनकी जगह - और _ का उपयोग करते हैं:

import base64 data = b'subjects?_d' safe = base64.urlsafe_b64encode(data).decode('ascii') print(safe) # c3ViamVjdHM_X2Q= print(base64.urlsafe_b64decode(safe)) # b'subjects?_d'

JWT यही रूप इस्तेमाल करता है, हालाँकि JWT = पैडिंग भी हटा देते हैं (नीचे देखें)। ज़्यादा संदर्भ के लिए Base64URL बनाम Base64 पढ़ें।

“Incorrect padding” त्रुटियाँ ठीक करना

अंत के = वर्णों के बिना Base64 डेटा, जो JWT और URL में आम है, डिकोड करते समय त्रुटि देता है:

binascii.Error: Incorrect padding

डिकोड करने से पहले पैडिंग वापस जोड़ें:

import base64 def b64url_decode(value: str) -> bytes: value += '=' * (-len(value) % 4) return base64.urlsafe_b64decode(value) def b64url_encode(raw: bytes) -> str: return base64.urlsafe_b64encode(raw).rstrip(b'=').decode('ascii')

व्यंजक -len(value) % 4 चार का गुणज बनाने के लिए ज़रूरी = वर्णों की संख्या (0, 1, 2 या 3) देता है।

इनपुट की जाँच करना

डिफ़ॉल्ट रूप से b64decode() Base64 वर्णमाला से बाहर के वर्णों को चुपचाप हटा देता है। लाइन ब्रेक वाले इनपुट के लिए यह सुविधाजनक है, लेकिन जब गलत डेटा को अस्वीकार करना ज़रूरी हो तो खतरनाक। सख़्त मोड चालू करने के लिए validate=True दें:

import base64, binascii try: base64.b64decode('SGVs bG8=', validate=True) except binascii.Error: print('Not valid Base64')

validate=True के साथ स्ट्रिंग के अंदर की खाली जगह अनदेखी होने के बजाय त्रुटि पैदा करती है।

अन्य उपयोगी फ़ंक्शन

  • base64.standard_b64encode() और standard_b64decode() मानक वर्णमाला के स्पष्ट नाम हैं।
  • base64.encodebytes() MIME ईमेल की तरह हर 76 वर्णों पर नई पंक्ति डालता है।
  • base64.b32encode() और b16encode() Base32 और हेक्साडेसिमल एन्कोडिंग देते हैं।

त्वरित संदर्भ

  • एन्कोड करने से पहले स्ट्रिंग को बाइट्स बनाना ज़रूरी है: .encode('utf-8')।
  • एन्कोड किया आउटपुट बाइट्स होता है; स्ट्रिंग के लिए .decode('ascii') कॉल करें।
  • फ़ाइलें 'rb' और 'wb' से खोलें।
  • URL और टोकन के लिए urlsafe_b64encode इस्तेमाल करें।
  • जब इनपुट अविश्वसनीय स्रोत से आए तो validate=True इस्तेमाल करें।
