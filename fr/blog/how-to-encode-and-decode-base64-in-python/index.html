Encoder et décoder Base64 en Python

Novembre 20267 min de lecture

Python inclut tout ce qu'il faut pour Base64 dans le module base64 de la bibliothèque standard. Le point essentiel à retenir : il travaille sur des octets (bytes), pas sur des chaînes de texte. La plupart des erreurs de débutant viennent de là. Ce guide montre comment encoder et décoder du texte et des fichiers, utiliser la variante adaptée aux URL et résoudre les erreurs que vous risquez de rencontrer.

Encoder une chaîne

Convertissez la chaîne en octets avec .encode(), passez les octets à b64encode(), puis reconvertissez le résultat en chaîne avec .decode() :

import base64 text = 'Hello, World!' encoded = base64.b64encode(text.encode('utf-8')).decode('ascii') print(encoded) # SGVsbG8sIFdvcmxkIQ==

b64encode() renvoie un objet bytes tel que b'SGVsbG8sIFdvcmxkIQ=='. Le décoder avec 'ascii' donne une chaîne ordinaire, ce qui est sans risque car la sortie Base64 ne contient que des caractères ASCII.

Décoder une chaîne

import base64 encoded = 'SGVsbG8sIFdvcmxkIQ==' decoded = base64.b64decode(encoded).decode('utf-8') print(decoded) # Hello, World!

b64decode() accepte aussi bien une str (contenant uniquement des caractères ASCII) que des bytes. Elle renvoie toujours des bytes ; appelez donc .decode('utf-8') quand vous attendez du texte. Si les données d'origine étaient binaires, comme une image, gardez-les sous forme d'octets.

Pourquoi vous obtenez « a bytes-like object is required »

Si vous passez une chaîne ordinaire à b64encode(), vous verrez :

TypeError: a bytes-like object is required, not 'str'

La solution est de convertir d'abord la chaîne en octets : base64.b64encode('text'.encode('utf-8')). C'est l'erreur Base64 la plus fréquente en Python.

Encoder et décoder des fichiers

Ouvrez les fichiers en mode binaire ('rb' et 'wb') pour que Python n'essaie pas d'interpréter les octets comme du texte :

import base64 # Encode a file with open('photo.png', 'rb') as f: encoded = base64.b64encode(f.read()).decode('ascii') # Decode it back to a file with open('copy.png', 'wb') as f: f.write(base64.b64decode(encoded))

Pour les très gros fichiers, évitez de tout charger en mémoire. base64.encode(input, output) et base64.decode(input, output) travaillent avec des objets fichier et traitent les données par blocs.

Construire un URI de données

Pour intégrer une image en HTML ou en CSS, faites précéder le texte Base64 du type de média :

import base64 with open('logo.png', 'rb') as f: data = base64.b64encode(f.read()).decode('ascii') data_uri = f'data:image/png;base64,{data}'

Si vous préférez une solution sans code, le convertisseur d'image en Base64 produit le même résultat dans votre navigateur.

Base64 adapté aux URL

Le Base64 standard utilise + et /, qui ont une signification particulière dans les URL. Le module propose des versions adaptées aux URL qui utilisent - et _ à la place :

import base64 data = b'subjects?_d' safe = base64.urlsafe_b64encode(data).decode('ascii') print(safe) # c3ViamVjdHM_X2Q= print(base64.urlsafe_b64decode(safe)) # b'subjects?_d'

C'est la variante utilisée par JWT, même si les JWT suppriment aussi le remplissage = (voir ci-dessous). Pour plus de contexte, lisez Base64URL vs Base64.

Corriger les erreurs « Incorrect padding »

Des données Base64 sans leurs caractères = finaux, ce qui est courant dans les JWT et les URL, provoquent une erreur au décodage :

binascii.Error: Incorrect padding

Rétablissez le remplissage avant de décoder :

import base64 def b64url_decode(value: str) -> bytes: value += '=' * (-len(value) % 4) return base64.urlsafe_b64decode(value) def b64url_encode(raw: bytes) -> str: return base64.urlsafe_b64encode(raw).rstrip(b'=').decode('ascii')

L'expression -len(value) % 4 donne le nombre de caractères = nécessaires (0, 1, 2 ou 3) pour atteindre un multiple de quatre.

Valider l'entrée

Par défaut, b64decode() ignore silencieusement les caractères qui ne font pas partie de l'alphabet Base64. C'est pratique pour des entrées contenant des sauts de ligne, mais dangereux quand il faut rejeter des données mal formées. Passez validate=True pour activer le mode strict :

import base64, binascii try: base64.b64decode('SGVs bG8=', validate=True) except binascii.Error: print('Not valid Base64')

Avec validate=True, l'espace à l'intérieur de la chaîne provoque une erreur au lieu d'être ignoré.

Autres fonctions utiles

  • base64.standard_b64encode() et standard_b64decode() sont des noms explicites pour l'alphabet standard.
  • base64.encodebytes() insère un saut de ligne tous les 76 caractères, comme le courrier MIME.
  • base64.b32encode() et b16encode() fournissent les encodages Base32 et hexadécimal.

Aide-mémoire

  • Les chaînes doivent devenir des octets avant l'encodage : .encode('utf-8').
  • La sortie encodée est en octets ; appelez .decode('ascii') pour obtenir une chaîne.
  • Ouvrez les fichiers avec 'rb' et 'wb'.
  • Utilisez urlsafe_b64encode pour les URL et les jetons.
  • Utilisez validate=True quand l'entrée provient d'une source non fiable.
