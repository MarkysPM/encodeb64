Base64 का उपयोग करके HTML ईमेल में इमेज कैसे एम्बेड करें

अगस्त 20265 मिनट पढ़ने का समय

यदि आपने कभी इमेज वाला HTML ईमेल भेजा है और प्राप्तकर्ता के इनबॉक्स में वे टूटी हुई दिखाई दी हैं, तो आप अकेले नहीं हैं। कई ईमेल क्लाइंट डिफ़ॉल्ट रूप से बाहरी रूप से होस्ट की गई इमेज को ब्लॉक कर देते हैं। एक भरोसेमंद तरीका यह है कि Base64 एन्कोडिंग का उपयोग करके इमेज को सीधे ईमेल में एम्बेड किया जाए — यह तकनीक इमेज के बाइनरी डेटा को एक टेक्स्ट स्ट्रिंग में बदल देती है, जिसे HTML के भीतर सीधे रखा जा सकता है।

HTML ईमेल में इमेज क्यों टूट जाती हैं

ईमेल में बाहरी इमेज तब लोड होती हैं जब प्राप्तकर्ता का ईमेल क्लाइंट उन्हें लाने के लिए एक HTTP रिक्वेस्ट भेजता है। Microsoft Outlook, Apple Mail और कॉर्पोरेट ईमेल सिस्टम जैसे कई क्लाइंट सुरक्षा कारणों से डिफ़ॉल्ट रूप से इन रिक्वेस्ट को ब्लॉक कर देते हैं। नतीजा यह होता है कि आपके सावधानी से डिज़ाइन किए गए बैनर या लोगो की जगह एक टूटी हुई इमेज का आइकन दिखाई देता है।

Base64 इमेज एम्बेडिंग क्या है?

Base64 एन्कोडिंग बाइनरी डेटा (जैसे इमेज फ़ाइल) को ASCII वर्णों की एक स्ट्रिंग में बदल देती है। जब आप किसी Base64-एन्कोडेड इमेज को HTML ईमेल में एम्बेड करते हैं, तो इमेज डेटा ईमेल के साथ ही यात्रा करता है — किसी बाहरी HTTP रिक्वेस्ट की आवश्यकता नहीं होती। HTML कुछ ऐसा दिखता है:

<img src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..." alt="कंपनी लोगो" />

data: प्रीफ़िक्स के बाद MIME टाइप और Base64 स्ट्रिंग को Data URI कहा जाता है। HTML रेंडर करने वाला हर प्रमुख ईमेल क्लाइंट Data URI से इमेज को सही ढंग से दिखा देगा।

चरण दर चरण: इमेज को Base64 में एन्कोड करना

चरण 1 — अपनी इमेज चुनें। इसे छोटा रखें। Base64 एन्कोडिंग फ़ाइल साइज़ को लगभग 33% बढ़ा देती है, और बड़ी एम्बेडेड इमेज आपके ईमेल का साइज़ बहुत बढ़ा देंगी, जिससे स्पैम फ़िल्टर सक्रिय हो सकते हैं। एन्कोडिंग से पहले इमेज को 50KB से कम रखने का लक्ष्य रखें।

चरण 2 — इमेज को एन्कोड करें। encodeb64.com/image-to-base64 पर जाएं, अपनी इमेज को अपलोड ज़ोन में ड्रैग और ड्रॉप करें, और आउटपुट फ़ॉर्मेट के रूप में "Data URI (HTML/CSS)" चुनें। Convert पर क्लिक करें। यह टूल सब कुछ आपके ब्राउज़र में ही प्रोसेस करता है — आपकी इमेज कभी आपके डिवाइस से बाहर नहीं जाती।

चरण 3 — Data URI कॉपी करें। आउटपुट कुछ ऐसा दिखेगा: data:image/png;base64,iVBORw0KGgo... पूरी स्ट्रिंग कॉपी करें।

चरण 4 — अपने HTML ईमेल टेम्पलेट में पेस्ट करें। अपनी इमेज के बाहरी src को Data URI से बदलें:

<img src="data:image/png;base64,iVBORw0KGgo..." alt="विवरण" width="200" height="60" />

हमेशा स्पष्ट रूप से width और height एट्रिब्यूट शामिल करें — कुछ ईमेल क्लाइंट को इमेज को सही आकार में दिखाने के लिए इनकी ज़रूरत होती है।

समर्थित इमेज फ़ॉर्मेट

अधिकांश ईमेल क्लाइंट PNG और JPEG Data URI को सपोर्ट करते हैं। लोगो और आइकन के लिए PNG की सिफ़ारिश की जाती है क्योंकि यह ट्रांसपेरेंसी को सपोर्ट करता है। Data URI में एनिमेटेड GIF से बचें — अधिकांश क्लाइंट केवल पहला फ़्रेम दिखाएंगे। SVG Data URI को ईमेल क्लाइंट में खराब सपोर्ट मिलता है और इनसे बचना चाहिए।

फ़ाइल साइज़ से जुड़ी बातें

Base64 एम्बेडिंग छोटी इमेज के लिए आदर्श है: लोगो, आइकन, हस्ताक्षर और सजावटी विभाजक। बड़ी हीरो इमेज या फ़ोटो बैनर के लिए, उन्हें बाहरी रूप से होस्ट करने और फ़ॉलबैक alt टेक्स्ट का उपयोग करने पर विचार करें, क्योंकि बड़ी इमेज एम्बेड करने से आपका ईमेल साइज़ लिमिट पार कर सकता है (कई सर्वर 10MB से बड़े ईमेल को अस्वीकार कर देते हैं) और लोड होने का समय काफी बढ़ जाता है।

ईमेल में Base64 का उपयोग कब नहीं करना चाहिए

  • 100KB से बड़ी न्यूज़लेटर हीरो इमेज — इसके बदले CDN पर होस्ट की गई इमेज का उपयोग करें
  • एनिमेटेड GIF — अधिकांश क्लाइंट में Base64 एनिमेशन खो देता है
  • बहुत सारी इमेज वाले ईमेल — सभी को एम्बेड करने से फ़ाइल बहुत बड़ी हो जाएगी
