Как кодировать и декодировать Base64 в Python

Ноябрь 20267 мин чтения

В Python всё необходимое для Base64 есть в модуле base64 стандартной библиотеки. Главное — помнить, что он работает с байтами, а не с текстовыми строками. Большинство ошибок новичков возникает именно из-за этого. В руководстве показано, как кодировать и декодировать текст и файлы, использовать вариант, безопасный для URL, и справляться с самыми вероятными ошибками.

Кодирование строки

Преобразуйте строку в байты через .encode(), передайте их в b64encode(), а результат превратите обратно в строку через .decode():

import base64 text = 'Hello, World!' encoded = base64.b64encode(text.encode('utf-8')).decode('ascii') print(encoded) # SGVsbG8sIFdvcmxkIQ==

b64encode() возвращает объект bytes, например b'SGVsbG8sIFdvcmxkIQ=='. Декодирование через 'ascii' даёт обычную строку — это безопасно, поскольку вывод Base64 содержит только ASCII-символы.

Декодирование строки

import base64 encoded = 'SGVsbG8sIFdvcmxkIQ==' decoded = base64.b64decode(encoded).decode('utf-8') print(decoded) # Hello, World!

b64decode() принимает как str (только с ASCII-символами), так и bytes. Она всегда возвращает bytes, поэтому вызывайте .decode('utf-8'), когда ожидаете текст. Если исходные данные были двоичными, например изображением, оставьте их байтами.

Почему появляется «a bytes-like object is required»

Если передать в b64encode() обычную строку, вы увидите:

TypeError: a bytes-like object is required, not 'str'

Решение — сначала преобразовать строку в байты: base64.b64encode('text'.encode('utf-8')). Это самая частая ошибка Base64 в Python.

Кодирование и декодирование файлов

Открывайте файлы в двоичном режиме ('rb' и 'wb'), чтобы Python не пытался трактовать байты как текст:

import base64 # Encode a file with open('photo.png', 'rb') as f: encoded = base64.b64encode(f.read()).decode('ascii') # Decode it back to a file with open('copy.png', 'wb') as f: f.write(base64.b64decode(encoded))

Для очень больших файлов не читайте всё в память. base64.encode(input, output) и base64.decode(input, output) работают с файловыми объектами и обрабатывают данные блоками.

Создание data URI

Чтобы встроить изображение в HTML или CSS, добавьте перед текстом Base64 тип носителя:

import base64 with open('logo.png', 'rb') as f: data = base64.b64encode(f.read()).decode('ascii') data_uri = f'data:image/png;base64,{data}'

Если не хотите писать код, конвертер изображений в Base64 даёт тот же результат прямо в браузере.

Base64, безопасный для URL

Стандартный Base64 использует + и /, имеющие особое значение в URL. В модуле есть безопасные для URL версии, где вместо них используются - и _:

import base64 data = b'subjects?_d' safe = base64.urlsafe_b64encode(data).decode('ascii') print(safe) # c3ViamVjdHM_X2Q= print(base64.urlsafe_b64decode(safe)) # b'subjects?_d'

Этот вариант применяется в JWT, хотя в JWT ещё и убирают дополнение = (см. ниже). Подробнее — в статье Base64URL и Base64.

Исправление ошибок «Incorrect padding»

Данные Base64 без завершающих символов =, что обычно для JWT и URL, вызывают ошибку при декодировании:

binascii.Error: Incorrect padding

Восстановите дополнение перед декодированием:

import base64 def b64url_decode(value: str) -> bytes: value += '=' * (-len(value) % 4) return base64.urlsafe_b64decode(value) def b64url_encode(raw: bytes) -> str: return base64.urlsafe_b64encode(raw).rstrip(b'=').decode('ascii')

Выражение -len(value) % 4 даёт количество нужных символов = (0, 1, 2 или 3), чтобы длина стала кратна четырём.

Проверка входных данных

По умолчанию b64decode() молча отбрасывает символы, не входящие в алфавит Base64. Это удобно для данных с переводами строк, но опасно, когда нужно отклонять некорректный ввод. Передайте validate=True, чтобы включить строгий режим:

import base64, binascii try: base64.b64decode('SGVs bG8=', validate=True) except binascii.Error: print('Not valid Base64')

С validate=True пробел внутри строки вызывает ошибку, а не игнорируется.

Другие полезные функции

  • base64.standard_b64encode() и standard_b64decode() — явные имена для стандартного алфавита.
  • base64.encodebytes() вставляет перевод строки каждые 76 символов, как MIME-почта.
  • base64.b32encode() и b16encode() реализуют кодирование Base32 и шестнадцатеричное.

Краткая памятка

  • Перед кодированием строки нужно превращать в байты: .encode('utf-8').
  • Результат кодирования — байты; вызовите .decode('ascii'), чтобы получить строку.
  • Открывайте файлы с 'rb' и 'wb'.
  • Для URL и токенов используйте urlsafe_b64encode.
  • Используйте validate=True, если данные приходят из недоверенного источника.
