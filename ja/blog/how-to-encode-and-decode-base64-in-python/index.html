PythonでBase64をエンコード・デコードする方法

2026年11月読了時間約7分

Pythonでは、標準ライブラリのbase64モジュールにBase64に必要なものがすべて揃っています。最も大切なのは、このモジュールがテキスト文字列ではなくバイト列を扱うという点です。初心者のエラーの多くは、これを忘れることから生まれます。このガイドでは、テキストとファイルのエンコード・デコード、URLセーフなバリエーションの使い方、遭遇しやすいエラーへの対処法を紹介します。

文字列をエンコードする

.encode()で文字列をバイト列に変換し、そのバイト列をb64encode()に渡して、結果を.decode()で文字列に戻します。

import base64 text = 'Hello, World!' encoded = base64.b64encode(text.encode('utf-8')).decode('ascii') print(encoded) # SGVsbG8sIFdvcmxkIQ==

b64encode()はb'SGVsbG8sIFdvcmxkIQ=='のようなbytesオブジェクトを返します。'ascii'でデコードすれば通常の文字列になり、Base64の出力はASCII文字だけなので安全です。

文字列をデコードする

import base64 encoded = 'SGVsbG8sIFdvcmxkIQ==' decoded = base64.b64decode(encoded).decode('utf-8') print(decoded) # Hello, World!

b64decode()は、str（ASCII文字のみ）とbytesのどちらも受け付けます。戻り値は常にbytesなので、テキストを期待する場合は.decode('utf-8')を呼び出してください。元のデータが画像などのバイナリだった場合は、バイト列のまま扱います。

「a bytes-like object is required」が出る理由

通常の文字列をb64encode()に渡すと、次のエラーが表示されます。

TypeError: a bytes-like object is required, not 'str'

解決策は、先に文字列をバイト列に変換することです：base64.b64encode('text'.encode('utf-8'))。これはPythonで最もよくあるBase64のエラーです。

ファイルのエンコードとデコード

ファイルはバイナリモード（'rb'と'wb'）で開き、Pythonがバイトをテキストとして解釈しようとしないようにします。

import base64 # Encode a file with open('photo.png', 'rb') as f: encoded = base64.b64encode(f.read()).decode('ascii') # Decode it back to a file with open('copy.png', 'wb') as f: f.write(base64.b64decode(encoded))

非常に大きなファイルでは、すべてをメモリに読み込むのは避けましょう。base64.encode(input, output)とbase64.decode(input, output)はファイルオブジェクトを扱い、データをチャンク単位で処理します。

data URIを作る

HTMLやCSSに画像を埋め込むには、Base64テキストの前にメディアタイプを付けます。

import base64 with open('logo.png', 'rb') as f: data = base64.b64encode(f.read()).decode('ascii') data_uri = f'data:image/png;base64,{data}'

コードを書かずに済ませたい場合は、画像からBase64への変換ツールで、ブラウザ上で同じ結果が得られます。

URLセーフなBase64

標準のBase64は、URLで特別な意味を持つ+と/を使います。このモジュールには、代わりに-と_を使うURLセーフ版があります。

import base64 data = b'subjects?_d' safe = base64.urlsafe_b64encode(data).decode('ascii') print(safe) # c3ViamVjdHM_X2Q= print(base64.urlsafe_b64decode(safe)) # b'subjects?_d'

これはJWTが使っているバリエーションですが、JWTは=のパディングも取り除きます（後述）。背景についてはBase64URLとBase64の違いをお読みください。

「Incorrect padding」エラーを修正する

JWTやURLでよくあるように、末尾の=がないBase64データをデコードするとエラーになります。

binascii.Error: Incorrect padding

デコードする前にパディングを復元します。

import base64 def b64url_decode(value: str) -> bytes: value += '=' * (-len(value) % 4) return base64.urlsafe_b64decode(value) def b64url_encode(raw: bytes) -> str: return base64.urlsafe_b64encode(raw).rstrip(b'=').decode('ascii')

式-len(value) % 4は、長さを4の倍数にするために必要な=の数（0、1、2、3のいずれか）を返します。

入力を検証する

既定では、b64decode()はBase64のアルファベットにない文字を黙って捨てます。改行を含む入力には便利ですが、不正なデータを拒否したいときには危険です。validate=Trueを渡すと、厳密モードになります。

import base64, binascii try: base64.b64decode('SGVs bG8=', validate=True) except binascii.Error: print('Not valid Base64')

validate=Trueを指定すると、文字列内のスペースは無視されずにエラーになります。

ほかの便利な関数

  • base64.standard_b64encode()とstandard_b64decode()は、標準アルファベットを明示した名前です。
  • base64.encodebytes()は、MIMEメールと同様に76文字ごとに改行を挿入します。
  • base64.b32encode()とb16encode()は、Base32と16進数のエンコードを提供します。

クイックリファレンス

  • エンコード前に、文字列をバイト列に変換する：.encode('utf-8')。
  • エンコード結果はバイト列。文字列にするには.decode('ascii')を呼ぶ。
  • ファイルは'rb'と'wb'で開く。
  • URLやトークンにはurlsafe_b64encodeを使う。
  • 信頼できない入力にはvalidate=Trueを使う。

出力を信頼できるツールと比較するには、エンコーダーやdecodeb64.comを使ってください。この形式が初めての方は、まずBase64エンコードとは？仕組みをわかりやすく解説からお読みください。
