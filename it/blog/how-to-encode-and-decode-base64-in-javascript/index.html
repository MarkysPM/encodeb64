Come codificare e decodificare Base64 in JavaScript

Novembre 20268 min di lettura

JavaScript offre diversi modi per lavorare con Base64 e quello giusto dipende da dove viene eseguito il codice. I browser forniscono btoa() e atob(). Node.js fornisce Buffer. Entrambi gli ambienti possono inoltre usare TextEncoder e TextDecoder per gestire correttamente Unicode. Questa guida copre ogni approccio e le trappole in cui cade la maggior parte degli sviluppatori.

Codifica di base con btoa() e atob()

btoa() (binary to ASCII) codifica una stringa in Base64 e atob() (ASCII to binary) la decodifica. Sono disponibili in tutti i browser moderni e in Node.js 16 e successivi.

const encoded = btoa('Hello, World!'); console.log(encoded); // "SGVsbG8sIFdvcmxkIQ==" const decoded = atob(encoded); console.log(decoded); // "Hello, World!"

Questo funziona con semplice testo ASCII. I problemi iniziano con tutto il resto.

Il problema di Unicode

btoa() tratta ogni carattere come un byte, quindi accetta solo caratteri con punti di codice da 0 a 255. Passargli un'emoji o la maggior parte dei testi non latini genera un errore:

btoa('café ☕'); // Uncaught InvalidCharacterError: String contains an invalid character

La soluzione è convertire prima la stringa in byte UTF-8 e poi codificare quei byte.

Codificare correttamente il testo Unicode

TextEncoder converte una stringa in un Uint8Array di byte UTF-8. Trasforma quei byte in una stringa binaria e passala a btoa():

function encodeBase64(text) { const bytes = new TextEncoder().encode(text); let binary = ''; bytes.forEach((b) => (binary += String.fromCharCode(b))); return btoa(binary); } function decodeBase64(base64) { const binary = atob(base64); const bytes = Uint8Array.from(binary, (c) => c.charCodeAt(0)); return new TextDecoder().decode(bytes); } encodeBase64('café ☕'); // "Y2Fmw6kg4piV" decodeBase64('Y2Fmw6kg4piV'); // "café ☕"

Usa queste due funzioni ogni volta che l'input può contenere qualcosa di più dell'ASCII di base. Vanno bene anche per qualsiasi testo scritto dagli utenti, come nomi, commenti o messaggi.

Base64 in Node.js con Buffer

In Node.js l'opzione più semplice e veloce è Buffer, che gestisce UTF-8 al posto tuo:

const encoded = Buffer.from('café ☕', 'utf8').toString('base64'); console.log(encoded); // "Y2Fmw6kg4piV" const decoded = Buffer.from(encoded, 'base64').toString('utf8'); console.log(decoded); // "café ☕"

btoa() e atob() esistono anche in Node.js, ma per il codice lato server è preferibile Buffer, perché lavora direttamente con i dati binari e non richiede il passaggio da una stringa.

Base64URL in JavaScript

Base64URL sostituisce + con -, / con _ e di solito rimuove il padding =. In Node.js 15.7 e successivi puoi richiederlo direttamente:

Buffer.from('subjects?_d').toString('base64url'); // "c3ViamVjdHM_X2Q"

Nel browser, converti tu stesso l'output standard:

function toBase64Url(base64) { return base64.replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, ''); } function fromBase64Url(base64url) { let base64 = base64url.replace(/-/g, '+').replace(/_/g, '/'); while (base64.length % 4) base64 += '='; return base64; }

Ricorda di ripristinare il padding prima di chiamare atob(), perché alcuni decodificatori rifiutano input la cui lunghezza non sia un multiplo di quattro.

Codificare un file o un'immagine

Nel browser, FileReader.readAsDataURL() legge un file e restituisce un URI di dati completo che contiene già i dati in Base64:

const input = document.querySelector('input[type="file"]'); input.addEventListener('change', () => { const reader = new FileReader(); reader.onload = () => { console.log(reader.result); // "data:image/png;base64,iVBORw0KGgo..." }; reader.readAsDataURL(input.files[0]); });

Per tenere solo la parte Base64, elimina tutto fino alla prima virgola: reader.result.split(',')[1]. Per una conversione rapida senza codice, usa il convertitore da immagine a Base64.

In Node.js, leggi il file in un buffer e codificalo:

import { readFileSync } from 'node:fs'; const base64 = readFileSync('photo.png').toString('base64');

Errori comuni e soluzioni

InvalidCharacterError: String contains an invalid character
Causa: hai passato a btoa() una stringa con caratteri oltre il punto di codice 255. Soluzione: codificala prima in byte UTF-8, come mostrato sopra.

InvalidCharacterError chiamando atob()
Causa: l'input contiene caratteri non presenti nell'alfabeto Base64, spesso - e _ di una stringa Base64URL, oppure spazi e interruzioni di riga. Soluzione: riconverti Base64URL in Base64 standard e rimuovi gli spazi alle estremità.

Il testo decodificato mostra caratteri strani come Ã©
Causa: i byte erano UTF-8 ma sono stati interpretati come Latin-1, che è ciò che atob() restituisce per impostazione predefinita. Soluzione: decodifica i byte con TextDecoder.

Output danneggiato con file grandi
Causa: costruire un'unica enorme stringa con String.fromCharCode(...bytes) può superare il limite di argomenti del motore. Soluzione: scorri i byte con un ciclo, elaborali a blocchi oppure usa FileReader o Buffer.

Una nota sulle API più recenti

I motori JavaScript più recenti stanno aggiungendo metodi integrati a Uint8Array per convertire da e verso Base64. Il supporto è ancora disomogeneo tra i browser, quindi controlla le tabelle di compatibilità aggiornate prima di farci affidamento in produzione. Le funzioni di questa guida oggi funzionano ovunque.
