JavaScript में Base64 एन्कोड और डिकोड कैसे करें

नवंबर 20268 मिनट पढ़ने का समय

JavaScript में Base64 के साथ काम करने के कई तरीके हैं, और सही तरीका इस पर निर्भर करता है कि आपका कोड कहाँ चलता है। ब्राउज़र btoa() और atob() देते हैं। Node.js Buffer देता है। दोनों वातावरणों में Unicode को सही ढंग से संभालने के लिए TextEncoder और TextDecoder भी इस्तेमाल किए जा सकते हैं। यह गाइड हर तरीके और उन जालों को कवर करती है जिनमें ज़्यादातर डेवलपर फँस जाते हैं।

btoa() और atob() से बुनियादी एन्कोडिंग

btoa() (binary to ASCII) किसी स्ट्रिंग को Base64 में एन्कोड करता है, और atob() (ASCII to binary) उसे डिकोड करता है। ये सभी आधुनिक ब्राउज़रों और Node.js 16 व उसके बाद के संस्करणों में उपलब्ध हैं।

const encoded = btoa('Hello, World!'); console.log(encoded); // "SGVsbG8sIFdvcmxkIQ==" const decoded = atob(encoded); console.log(decoded); // "Hello, World!"

यह सादे ASCII टेक्स्ट के लिए काम करता है। समस्या किसी भी और चीज़ से शुरू होती है।

Unicode की समस्या

btoa() हर वर्ण को एक बाइट मानता है, इसलिए यह केवल 0 से 255 कोड पॉइंट वाले वर्ण स्वीकार करता है। इमोजी या ज़्यादातर गैर-लैटिन टेक्स्ट देने पर त्रुटि आती है:

btoa('café ☕'); // Uncaught InvalidCharacterError: String contains an invalid character

समाधान यह है कि पहले स्ट्रिंग को UTF-8 बाइट्स में बदलें, फिर उन बाइट्स को एन्कोड करें।

Unicode टेक्स्ट को सही ढंग से एन्कोड करना

TextEncoder किसी स्ट्रिंग को UTF-8 बाइट्स के Uint8Array में बदलता है। उन बाइट्स को बाइनरी स्ट्रिंग बनाएँ और btoa() को दें:

function encodeBase64(text) { const bytes = new TextEncoder().encode(text); let binary = ''; bytes.forEach((b) => (binary += String.fromCharCode(b))); return btoa(binary); } function decodeBase64(base64) { const binary = atob(base64); const bytes = Uint8Array.from(binary, (c) => c.charCodeAt(0)); return new TextDecoder().decode(bytes); } encodeBase64('café ☕'); // "Y2Fmw6kg4piV" decodeBase64('Y2Fmw6kg4piV'); // "café ☕"

जब भी इनपुट में सामान्य ASCII से ज़्यादा कुछ हो सकता है, इन दोनों फ़ंक्शन का उपयोग करें। ये उपयोगकर्ताओं द्वारा लिखे किसी भी टेक्स्ट, जैसे नाम, टिप्पणियाँ या संदेश, के लिए भी काम करते हैं।

Buffer के साथ Node.js में Base64

Node.js में सबसे सरल और तेज़ विकल्प Buffer है, जो आपके लिए UTF-8 संभाल लेता है:

const encoded = Buffer.from('café ☕', 'utf8').toString('base64'); console.log(encoded); // "Y2Fmw6kg4piV" const decoded = Buffer.from(encoded, 'base64').toString('utf8'); console.log(decoded); // "café ☕"

Node.js में btoa() और atob() भी मौजूद हैं, लेकिन सर्वर कोड के लिए Buffer बेहतर है क्योंकि यह बाइनरी डेटा के साथ सीधे काम करता है और इसे स्ट्रिंग के रास्ते से गुज़रने की ज़रूरत नहीं पड़ती।

JavaScript में Base64URL

Base64URL + को -, / को _ से बदलता है और आम तौर पर = पैडिंग हटा देता है। Node.js 15.7 और उसके बाद के संस्करणों में आप इसे सीधे माँग सकते हैं:

Buffer.from('subjects?_d').toString('base64url'); // "c3ViamVjdHM_X2Q"

ब्राउज़र में मानक आउटपुट को खुद बदलें:

function toBase64Url(base64) { return base64.replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, ''); } function fromBase64Url(base64url) { let base64 = base64url.replace(/-/g, '+').replace(/_/g, '/'); while (base64.length % 4) base64 += '='; return base64; }

atob() को कॉल करने से पहले पैडिंग वापस जोड़ना न भूलें, क्योंकि कुछ डिकोडर ऐसे इनपुट अस्वीकार कर देते हैं जिनकी लंबाई चार का गुणज नहीं होती।

फ़ाइल या इमेज को एन्कोड करना

ब्राउज़र में FileReader.readAsDataURL() फ़ाइल पढ़कर पूरा data URI लौटाता है, जिसमें Base64 डेटा पहले से मौजूद होता है:

const input = document.querySelector('input[type="file"]'); input.addEventListener('change', () => { const reader = new FileReader(); reader.onload = () => { console.log(reader.result); // "data:image/png;base64,iVBORw0KGgo..." }; reader.readAsDataURL(input.files[0]); });

केवल Base64 वाला हिस्सा रखना हो तो पहले अल्पविराम तक का सब कुछ हटा दें: reader.result.split(',')[1]। बिना कोड के तेज़ रूपांतरण के लिए इमेज से Base64 कन्वर्टर का उपयोग करें।

Node.js में फ़ाइल को बफ़र में पढ़ें और उसे एन्कोड करें:

import { readFileSync } from 'node:fs'; const base64 = readFileSync('photo.png').toString('base64');

आम त्रुटियाँ और समाधान

InvalidCharacterError: String contains an invalid character
कारण: आपने btoa() को ऐसी स्ट्रिंग दी जिसमें कोड पॉइंट 255 से ऊपर के वर्ण हैं। समाधान: ऊपर दिखाए अनुसार पहले उसे UTF-8 बाइट्स में एन्कोड करें।

atob() कॉल करते समय InvalidCharacterError
कारण: इनपुट में ऐसे वर्ण हैं जो Base64 वर्णमाला में नहीं हैं, अक्सर Base64URL स्ट्रिंग के - और _, या खाली स्थान और लाइन ब्रेक। समाधान: Base64URL को वापस मानक Base64 में बदलें और किनारों की खाली जगह हटाएँ।

डिकोड किए गए टेक्स्ट में Ã© जैसे अजीब वर्ण दिखना
कारण: बाइट्स UTF-8 थे लेकिन उन्हें Latin-1 के रूप में पढ़ा गया, जो atob() डिफ़ॉल्ट रूप से लौटाता है। समाधान: बाइट्स को TextDecoder से डिकोड करें।

बड़ी फ़ाइलों में आउटपुट का खराब होना
कारण: String.fromCharCode(...bytes) से एक विशाल स्ट्रिंग बनाने पर इंजन की आर्गुमेंट सीमा पार हो सकती है। समाधान: बाइट्स पर लूप चलाएँ, उन्हें हिस्सों में प्रोसेस करें, या FileReader अथवा Buffer का उपयोग करें।

नए API पर एक टिप्पणी

नए JavaScript इंजन Uint8Array पर Base64 से और में बदलने के अंतर्निहित मेथड जोड़ रहे हैं। ब्राउज़रों में इनका समर्थन अभी असमान है, इसलिए प्रोडक्शन में इन पर निर्भर होने से पहले ताज़ा संगतता तालिकाएँ देखें। इस गाइड के फ़ंक्शन आज हर जगह काम करते हैं।
