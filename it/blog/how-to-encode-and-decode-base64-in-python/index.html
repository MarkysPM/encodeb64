Come codificare e decodificare Base64 in Python

Novembre 20267 min di lettura

Python include tutto ciò che serve per Base64 nel modulo base64 della libreria standard. La cosa più importante da ricordare è che lavora con i byte, non con le stringhe di testo. La maggior parte degli errori dei principianti nasce dal dimenticarlo. Questa guida mostra come codificare e decodificare testo e file, usare la variante sicura per gli URL e gestire gli errori che incontrerai più probabilmente.

Codificare una stringa

Converti la stringa in byte con .encode(), passa i byte a b64encode() e riconverti il risultato in stringa con .decode():

import base64 text = 'Hello, World!' encoded = base64.b64encode(text.encode('utf-8')).decode('ascii') print(encoded) # SGVsbG8sIFdvcmxkIQ==

b64encode() restituisce un oggetto bytes come b'SGVsbG8sIFdvcmxkIQ=='. Decodificarlo con 'ascii' dà una normale stringa, ed è sicuro perché l'output di Base64 contiene solo caratteri ASCII.

Decodificare una stringa

import base64 encoded = 'SGVsbG8sIFdvcmxkIQ==' decoded = base64.b64decode(encoded).decode('utf-8') print(decoded) # Hello, World!

b64decode() accetta sia una str (contenente solo caratteri ASCII) sia dei bytes. Restituisce sempre bytes, quindi chiama .decode('utf-8') quando ti aspetti del testo. Se i dati originali erano binari, come un'immagine, lasciali come byte.

Perché compare «a bytes-like object is required»

Se passi una normale stringa a b64encode() vedrai:

TypeError: a bytes-like object is required, not 'str'

La soluzione è convertire prima la stringa in byte: base64.b64encode('text'.encode('utf-8')). È l'errore Base64 più comune in Python.

Codificare e decodificare file

Apri i file in modalità binaria ('rb' e 'wb') in modo che Python non cerchi di interpretare i byte come testo:

import base64 # Encode a file with open('photo.png', 'rb') as f: encoded = base64.b64encode(f.read()).decode('ascii') # Decode it back to a file with open('copy.png', 'wb') as f: f.write(base64.b64decode(encoded))

Per file molto grandi, evita di leggere tutto in memoria. base64.encode(input, output) e base64.decode(input, output) lavorano con oggetti file ed elaborano i dati a blocchi.

Creare un URI di dati

Per incorporare un'immagine in HTML o CSS, anteponi il tipo di media al testo Base64:

import base64 with open('logo.png', 'rb') as f: data = base64.b64encode(f.read()).decode('ascii') data_uri = f'data:image/png;base64,{data}'

Se preferisci un'opzione senza codice, il convertitore da immagine a Base64 produce lo stesso risultato nel tuo browser.

Base64 sicuro per gli URL

Il Base64 standard usa + e /, che hanno un significato speciale negli URL. Il modulo offre versioni sicure per gli URL che usano invece - e _:

import base64 data = b'subjects?_d' safe = base64.urlsafe_b64encode(data).decode('ascii') print(safe) # c3ViamVjdHM_X2Q= print(base64.urlsafe_b64decode(safe)) # b'subjects?_d'

È la variante usata da JWT, anche se i JWT eliminano pure il padding = (vedi sotto). Per approfondire, leggi Base64URL vs Base64.

Correggere gli errori «Incorrect padding»

I dati Base64 privi dei caratteri = finali, cosa comune in JWT e URL, generano un errore in fase di decodifica:

binascii.Error: Incorrect padding

Ripristina il padding prima di decodificare:

import base64 def b64url_decode(value: str) -> bytes: value += '=' * (-len(value) % 4) return base64.urlsafe_b64decode(value) def b64url_encode(raw: bytes) -> str: return base64.urlsafe_b64encode(raw).rstrip(b'=').decode('ascii')

L'espressione -len(value) % 4 restituisce il numero di caratteri = necessari (0, 1, 2 o 3) per arrivare a un multiplo di quattro.

Validare l'input

Per impostazione predefinita, b64decode() scarta in silenzio i caratteri che non appartengono all'alfabeto Base64. È comodo con input che contengono interruzioni di riga, ma pericoloso quando devi rifiutare dati malformati. Passa validate=True per attivare la modalità rigorosa:

import base64, binascii try: base64.b64decode('SGVs bG8=', validate=True) except binascii.Error: print('Not valid Base64')

Con validate=True lo spazio dentro la stringa provoca un errore invece di essere ignorato.

Altre funzioni utili

  • base64.standard_b64encode() e standard_b64decode() sono nomi espliciti per l'alfabeto standard.
  • base64.encodebytes() inserisce un'interruzione di riga ogni 76 caratteri, come la posta MIME.
  • base64.b32encode() e b16encode() offrono le codifiche Base32 ed esadecimale.

Riepilogo rapido

  • Le stringhe devono diventare byte prima della codifica: .encode('utf-8').
  • L'output codificato è in byte; chiama .decode('ascii') per ottenere una stringa.
  • Apri i file con 'rb' e 'wb'.
  • Usa urlsafe_b64encode per URL e token.
  • Usa validate=True quando l'input proviene da una fonte non attendibile.
