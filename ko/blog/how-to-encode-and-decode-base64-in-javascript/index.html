JavaScript에서 Base64 인코딩과 디코딩하는 방법

2026년 11월읽는 시간 약 8분

JavaScript에서 Base64를 다루는 방법은 여러 가지이며, 적절한 방법은 코드가 실행되는 환경에 따라 달라집니다. 브라우저에는 btoa()와 atob()가 있고, Node.js에는 Buffer가 있습니다. 두 환경 모두 TextEncoder와 TextDecoder를 사용해 유니코드를 올바르게 처리할 수 있습니다. 이 가이드에서는 각 방식과 대부분의 개발자가 걸려 넘어지는 함정을 다룹니다.

btoa()와 atob()를 이용한 기본 인코딩

btoa()(binary to ASCII)는 문자열을 Base64로 인코딩하고, atob()(ASCII to binary)는 이를 디코딩합니다. 모든 최신 브라우저와 Node.js 16 이상에서 사용할 수 있습니다.

const encoded = btoa('Hello, World!'); console.log(encoded); // "SGVsbG8sIFdvcmxkIQ==" const decoded = atob(encoded); console.log(decoded); // "Hello, World!"

단순한 ASCII 텍스트에서는 잘 동작합니다. 문제는 그 밖의 문자에서 시작됩니다.

유니코드 문제

btoa()는 각 문자를 1바이트로 취급하므로 코드 포인트가 0에서 255 사이인 문자만 받습니다. 이모지나 대부분의 비라틴 문자 텍스트를 넘기면 오류가 발생합니다.

btoa('café ☕'); // Uncaught InvalidCharacterError: String contains an invalid character

해결책은 문자열을 먼저 UTF-8 바이트로 변환한 다음 그 바이트를 인코딩하는 것입니다.

유니코드 텍스트를 올바르게 인코딩하기

TextEncoder는 문자열을 UTF-8 바이트로 이루어진 Uint8Array로 변환합니다. 그 바이트를 이진 문자열로 만든 뒤 btoa()에 넘깁니다.

function encodeBase64(text) { const bytes = new TextEncoder().encode(text); let binary = ''; bytes.forEach((b) => (binary += String.fromCharCode(b))); return btoa(binary); } function decodeBase64(base64) { const binary = atob(base64); const bytes = Uint8Array.from(binary, (c) => c.charCodeAt(0)); return new TextDecoder().decode(bytes); } encodeBase64('café ☕'); // "Y2Fmw6kg4piV" decodeBase64('Y2Fmw6kg4piV'); // "café ☕"

입력에 기본 ASCII 이외의 문자가 있을 수 있다면 항상 이 두 함수를 사용하세요. 이름, 댓글, 메시지처럼 사용자가 입력한 어떤 텍스트에도 쓸 수 있습니다.

Node.js에서 Buffer로 Base64 다루기

Node.js에서는 Buffer가 가장 간단하고 빠른 방법이며 UTF-8도 알아서 처리해 줍니다.

const encoded = Buffer.from('café ☕', 'utf8').toString('base64'); console.log(encoded); // "Y2Fmw6kg4piV" const decoded = Buffer.from(encoded, 'base64').toString('utf8'); console.log(decoded); // "café ☕"

Node.js에도 btoa()와 atob()가 있지만, 서버 코드에서는 바이너리 데이터를 직접 다루고 문자열을 거치지 않아도 되는 Buffer를 권장합니다.

JavaScript의 Base64URL

Base64URL은 +를 -로, /를 _로 바꾸고 보통 = 패딩을 제거합니다. Node.js 15.7 이상에서는 바로 요청할 수 있습니다.

Buffer.from('subjects?_d').toString('base64url'); // "c3ViamVjdHM_X2Q"

브라우저에서는 표준 출력을 직접 변환합니다.

function toBase64Url(base64) { return base64.replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, ''); } function fromBase64Url(base64url) { let base64 = base64url.replace(/-/g, '+').replace(/_/g, '/'); while (base64.length % 4) base64 += '='; return base64; }

atob()를 호출하기 전에 패딩을 복원하는 것을 잊지 마세요. 일부 디코더는 길이가 4의 배수가 아닌 입력을 거부하기 때문입니다.

파일이나 이미지 인코딩하기

브라우저에서는 FileReader.readAsDataURL()이 파일을 읽어 Base64 데이터가 이미 들어 있는 완전한 data URI를 반환합니다.

const input = document.querySelector('input[type="file"]'); input.addEventListener('change', () => { const reader = new FileReader(); reader.onload = () => { console.log(reader.result); // "data:image/png;base64,iVBORw0KGgo..." }; reader.readAsDataURL(input.files[0]); });

Base64 부분만 필요하다면 첫 번째 쉼표 앞까지를 제거하세요: reader.result.split(',')[1]. 코드 없이 빠르게 변환하려면 이미지 Base64 변환기를 사용하세요.

Node.js에서는 파일을 버퍼로 읽어 인코딩합니다.

import { readFileSync } from 'node:fs'; const base64 = readFileSync('photo.png').toString('base64');

흔한 오류와 해결 방법

InvalidCharacterError: String contains an invalid character
원인: 코드 포인트 255를 넘는 문자가 들어 있는 문자열을 btoa()에 넘겼습니다. 해결: 위에서 보인 것처럼 먼저 UTF-8 바이트로 인코딩하세요.

atob() 호출 시 InvalidCharacterError
원인: 입력에 Base64 알파벳에 없는 문자가 들어 있습니다. Base64URL 문자열의 -와 _, 또는 공백과 줄 바꿈인 경우가 많습니다. 해결: Base64URL을 표준 Base64로 되돌리고 앞뒤 공백을 제거하세요.

디코딩한 텍스트에 Ã© 같은 이상한 문자가 보임
원인: 바이트는 UTF-8인데 atob()가 기본으로 반환하는 Latin-1로 해석되었습니다. 해결: TextDecoder로 바이트를 디코딩하세요.

큰 파일에서 출력이 손상됨
원인: String.fromCharCode(...bytes)로 거대한 문자열을 한 번에 만들면 엔진의 인수 개수 제한을 넘을 수 있습니다. 해결: 바이트를 반복문으로 처리하거나 청크 단위로 나누어 처리하거나, FileReader 또는 Buffer를 사용하세요.
