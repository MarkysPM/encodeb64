如何使用 Base64 在 HTML 邮件中嵌入图片

2026年8月阅读时间约 5 分钟

如果你曾经发送过带图片的 HTML 邮件，却发现收件人收到的邮件里图片显示不出来，你并不是唯一遇到这个问题的人。许多邮件客户端默认会阻止加载外部托管的图片。一个可靠的解决方案是使用 Base64 编码直接将图片嵌入邮件——这种技术会把图片的二进制数据转换成一段文本字符串，可以直接放在 HTML 中。

为什么 HTML 邮件中的图片会显示不出来

邮件中的外部图片依赖收件人的邮件客户端发起 HTTP 请求来加载。许多客户端——包括 Microsoft Outlook、Apple Mail 以及企业邮件系统——出于安全原因，默认会阻止这些请求。结果就是本应显示精心设计的横幅或 Logo 的地方，出现了一个图片损坏的图标。

什么是 Base64 图片嵌入？

Base64 编码会把二进制数据（比如一个图片文件）转换成一串 ASCII 字符。当你在 HTML 邮件中嵌入一个 Base64 编码的图片时，图片数据会随邮件本身一起传输——不需要任何外部 HTTP 请求。HTML 代码是这样的：

<img src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..." alt="公司Logo" />

data: 前缀加上 MIME 类型和 Base64 字符串，被称为 Data URI。所有主流支持渲染 HTML 的邮件客户端都能正确显示来自 Data URI 的图片。

分步教程：将图片编码为 Base64

第一步——选择你的图片。尽量保持体积小。Base64 编码会使文件大小增加约 33%，嵌入的图片过大会显著增加邮件体积，可能触发垃圾邮件过滤器。建议编码前图片小于 50KB。

第二步——编码图片。访问 encodeb64.com/image-to-base64，把图片拖放到上传区域，并选择输出格式为“Data URI (HTML/CSS)”，然后点击“Convert”。该工具完全在你的浏览器中处理——图片不会离开你的设备。

第三步——复制 Data URI。输出结果类似这样：data:image/png;base64,iVBORw0KGgo... 复制整个字符串。

第四步——粘贴到你的 HTML 邮件模板中。将图片的外部 src 替换为 Data URI：

<img src="data:image/png;base64,iVBORw0KGgo..." alt="描述" width="200" height="60" />

务必显式设置 width 和 height 属性——部分邮件客户端需要这两个属性才能以正确尺寸渲染图片。

支持的图片格式

大多数邮件客户端都支持 PNG 和 JPEG 格式的 Data URI。对于 Logo 和图标，推荐使用 PNG，因为它支持透明度。请避免在 Data URI 中使用动态 GIF——大多数客户端只会显示第一帧。SVG 格式的 Data URI 在邮件客户端中的支持很差，应尽量避免使用。

文件大小方面的考虑

Base64 嵌入最适合小图片：Logo、图标、签名和装饰性分隔线。对于大型主图或照片横幅，建议将其托管在外部并使用备用的 alt 文本，因为嵌入大图片可能导致邮件超出大小限制（许多服务器会拒绝超过 10MB 的邮件），并显著增加加载时间。

何时不应在邮件中使用 Base64

  • 大于 100KB 的邮件通讯主图——应改用 CDN 托管的图片
  • 动态 GIF——大多数客户端下 Base64 会丢失动画效果
  • 包含大量图片的邮件——全部嵌入会让文件体积急剧膨胀
